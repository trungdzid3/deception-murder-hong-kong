THIS FILE CONTAINS NO SPOILERS


WHAT IS THIS?

This project is an unofficial update to the Engish edition of Ystari's version of Sherlock Holmes Consulting Detective.  The purpose is to provide replacement pages to make the game more functionally match the French edition.  Ystari is not responsible for its contents.

Currently, the errata covers Cases 3 and 6 and two newspapers pages.  

I'm not sure if anything else is needed.


WHAT IS INCLUDED?

READMEFIRST.TXT - The file you're reading.  A spoiler-free explanation of the whats and whys of this project
SHCD-ERRATA-CASEXX.PDF - Replacement pages for Case XX, original font, no background, on Letter size paper
SHCD-ERRATA-TIMES-XXXX.XX.XX.PX.PDF - Replacement pages for Newspaper YEAR.MONTH.DAY.PAGE
SPOILERS-CASEXX.TXT - A very rough list of what was changed and why. Don't read this.
SPOILERS-TIMES.TXT - A list of what was changed and why. It starts with a listing of which Case each newspaper page is needed for.


WHY IS THIS NECESSARY?

Ystari bought the Sleuth version of Sherlock Holmes Consulting Detective and made many really great changes.  Among other things, they put each case in its own beautiful booklet, updated all the graphics and fonts, printed the London Time's pages on large newspaper-like stock, updated the rules and addressed concerns that they had with several of the cases.  

The changes they made to the actual case content were originally written in French, intended for their flagship French edition.  When they produced the English edition it appears they used 95+% of the text from the original Sleuth English game and updated it with translations of the changes made to their French edition.  In that process, certain changes were overlooked and left out of the printing.  This is most apparent in the two cases where Ystari changed the solutions: The Mystified Murderess (Case 3) and The Mummy's Curse (Case 6).  The clues that were mistakenly not updated make the cases harder to properly solve, because the unchanged text often pointed players toward the old, now obsolete solution.  

Ystari has not yet offerred errata for these cases, so I enlisted the help of a translator and made this unofficial errata hoping future players will avoid the frustrations many of us felt playing these cases for the first time.


WHAT IS IN THE ERRATA?

You can read the SPOILER.TXT file if you want to see exactly what was "fixed."  The spoiler-free answer is that I incorporated the differences between the English and French editions which I thought were important to helping players arrive at Ystari's solution to the case.  We have not gone out of our way to correct typos or other non-functional differences. We also have not added anything that wasn't in the French edition.  

I'm also not trying to undo what Ystari intended to change.  For example, a lot of people prefer the original 80s solutions for Cases 3 and 6.  While I was tempted to create an another set of files that would let people play using those old solutions, I decided against it for several reasons.  I'll leave that to someone else.

I've also tried to keep the replacement pages to a minimum. If I were to try and fix everything it would lead to a cumbersome ammount of print-outs, which I feared would take players out of the game.  

If you think I've left something important out, have a look through the translators notes in the spoiler files and let me know!


HOW DO I USE THIS?

If you have a regular home printer send the file SHCD-ERRATA-CASEXX.PDF files to it. The pages will replace corresponding pages in the original Case booklets.  They are formatted to look like the originals, except with no background and fitted to standard Letter (8.5"x11") paper.

If you have access to a nice color printer and A4 size glossy paper, you should download the errata from here: https://drive.google.com/file/d/0B8pkvwyFQ4sZVUVtRkx3UHJpNjQ/view. Then print out SHCD-ERRATA-CASEXX-HQ.PDFs, which have the same pages, but formatted to look almost identical to the originals, including proper page dimensions and color background.  Since text was added to these pages, the font size and line spacing had to be altered slightly so everything would still fit on one page.

Or, if you really dislike the font or formatting I've used, you can copy an paste the text from either of the PDF files and reformat as you like.

Print out the newspaper pages however you like.  


ARE THE ERRATA FILES SPOILER FREE?

I've put some thought into how to present this information without spoiling anything for you.  For one, I decided I needed to release full page replacements, instead of just the text or clues that were changed.  This was so players wouldn't be alerted that a certain clue was important to solving the game.  Also, each page starts and ends at the same spot as the original pages, despite having more text.  If you don't compare these new pages with the originals, you shouldn't notice what was changed, and therefore what is important to solving the case.

For the newspapers I've decided not to tell players which cases they fix.  This is the least spoilery solution I could find.  If you really want to know which cases you need them for, check out the first few lines of SPOILERS-TIMES.txt. It tells you without spoiling the errata contents.  


WILL ERRATA BE RELEASE FOR CASE __?

I'm not sure yet.  Whats done so far covers the biggest problems that I'm aware of.  My translator and only source for the French edition is busy with other projects.  

If you think errata should be made for other cases, I'd be happy to hear why.  My criteria is generally if Sherlock's solution doesn't match the info found in the locations he used, then its worth looking into.
