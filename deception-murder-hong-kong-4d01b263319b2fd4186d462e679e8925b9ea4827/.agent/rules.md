# Rules for Deception - Murder in Hong Kong Project

Tệp này chứa các quy tắc thiết kế, lập trình và vận hành cho dự án mô phỏng hoặc hỗ trợ trò chơi boardgame Deception: Murder in Hong Kong.

## Quy tắc thiết kế UI/UX
- Giao diện phải mang đậm phong cách trinh thám, bí ẩn (Sử dụng màu tối như xám đậm, xanh đen, đỏ rượu vang).
- Các thẻ đầu mối, công cụ, vai trò cần được hiển thị trực quan và đẹp mắt.
- Hỗ trợ responsive tốt trên thiết bị di động (vì người chơi thường dùng điện thoại để xem bài của mình khi chơi offline).

## Quy tắc Code
- Viết code sạch, modular.
- Tách biệt logic game, dữ liệu thẻ bài và giao diện UI.
