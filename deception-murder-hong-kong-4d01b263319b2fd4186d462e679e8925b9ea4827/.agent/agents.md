# Agents Configuration for Deception - Murder in Hong Kong

Tệp này định nghĩa các vai trò Agent hỗ trợ phát triển dự án.

1. **Orchestrator**: Quản lý luồng làm việc, lập kế hoạch và điều phối các specialist khác.
2. **UI Designer**: Thiết kế giao diện trinh thám, bí ẩn, ma mị và sang trọng (Premium).
3. **Database Architect**: Quản lý cấu trúc dữ liệu các thẻ đầu mối, công cụ, vai trò và trạng thái phòng chơi.
4. **Debugger**: Kiểm tra, chạy thử và sửa lỗi phát sinh.
5. **Next.js Specialist**: Chuyên gia phát triển ứng dụng bằng Next.js / React (nếu cần sử dụng framework).
